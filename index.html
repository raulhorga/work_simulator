Ghid de utilizare — Simulator linie de producție

Aplicația simulează local o bandă ovală continuă, stații de procesare, roboți de manipulare, rute alternative și evacuare. Nu trimite date către un server.

1. Primii pași

  1. Deschide fișierul HTML în Chrome sau Edge.
  2. Alege tema Black / White / Grey și limba RO / EN.
  3. Setează forma benzii, intrarea, ieșirea și sensul de deplasare.
  4. Adaugă stațiile și configurează timpii, capacitățile și ruta.
  5. Apasă Continuă pentru rulare sau Pauză pentru oprire temporară.
  6. Verifică piesele și jurnalul de evenimente JSON.

2. Configurarea benzii

  • Formă bandă: rotundă pentru circuit circular, ovală pentru buclă alungită sau dreaptă cu retur îngust și gol.
  • Lungime porțiune dreaptă: reglează segmentul activ în forma ovală sau dreaptă.
  • Diametru: reglează dimensiunea buclei rotunde sau ovalului.
  • Lățime bandă: modifică grosimea desenului.
  • Orar / Antiorar: schimbă sensul pentru buclele închise.
  • Intrare / Ieșire: mută marcajele de pe traseu sau etichetele separat.
  • Semafor LINIE: oprește/pornește toate operațiile, inclusiv alimentarea feederelor.

3. Adăugarea și poziționarea stațiilor

Apasă + Proces pentru o stație simplă sau + Robot + proces pentru un robot care preia piesa și o transportă la un proces din afara benzii. Trage marcajul stației pe bandă; alternativ, editează poziția procentuală. Butonul Șterge elimină stația. Modificările structurale pot reseta piesele din simulare.

4. Parametrii unei stații

  • Nume: denumirea vizibilă.
  • Capacitate totală: numărul maxim de piese aflate în buffer și în etapele stației.
  • Durată proces: timpul operației.
  • Procese paralele: câte piese poate procesa simultan stația.
  • Ridicare / Repunere: timpii de manipulare ai piesei.
  • Robot: timp de transport pe sens și capacitatea de operații simultane.
  • Rată FAIL (%): probabilitatea simulată de NOK la încheierea procesului.

5. Procese alternative și ordinea logică

Setează același Grup alternativ pentru până la 8 stații (ex. GRUP_A). În Secvență de procesare scrie ST01,GRUP_A,ST05, apoi apasă Aplică ruta. La etapa GRUP_A piesa poate fi preluată de o stație disponibilă din grup. Pozițiile fizice și ordinea logică sunt configurate separat. Aceasta este o rutare prin secvențe/grupuri, nu un editor complet IF/ELSE.

6. FAIL și puncte NOK

La fiecare stație poți introduce o rată FAIL între 0 și 100%. Folosește + Poziție NOK pentru a adăuga puncte de respingere; le poți muta pe bandă și redenumi. O piesă care eșuează primește un eveniment process_failed și este direcționată către un punct NOK configurat.

7a. Semafor și buffere între procese

Configurează pentru fiecare stație capacitatea bufferului de așteptare (0–500 piese). Când stația este plină, piesele se acumulează fizic înaintea ei. Un buffer local plin propagă blocajul spre stația anterioară, dar procesele din aval continuă. Alimentarea continuă cât timp există loc la INTRARE. ROȘU indică saturație locală, nu oprire globală. Valoarea 0 înseamnă fără buffer suplimentar.

7. Blocaj în cascadă (capacitate + buffer BEFORE)

O stație continuă să proceseze când bufferul ei BEFORE este plin. Când ocuparea stației următoare plus piesele din bufferul BEFORE ating suma capacităților configurate, este blocată ieșirea stației anterioare. Piesa terminată rămâne în stația anterioară până apare loc. Blocajul se propagă în amonte, nu oprește stațiile din aval.

8. Bufferul de ieșire

Configurează Durată evacuare / piesă și Capacitate evacuare simultană. Bufferul de ieșire păstrează maximum 1.000 de piese în așteptare; când este plin, piesele rămân pe bandă până apare loc. Numai piesele evacuate complet sunt numărate drept finalizate. Piesele cu operații obligatorii incomplete sunt reținute separat, maximum 1.000; atingerea acestei limite blochează alimentarea. Jurnalul exportă ultimele 5.000 de evenimente, iar contorul afișează totalul de la resetare. Browserul poate suspenda filele inactive; pentru rulare continuă păstrează fila activă, dezactivează economisirea memoriei pentru ea și evită repausul calculatorului.

Evacuare incompletă: ordinea afișată include INTRARE și IEȘIRE. Bifează Permite evacuarea pieselor incomplete pentru a scoate piesele la IEȘIRE chiar dacă mai au procese de parcurs. Acestea apar la Incomplete evacuate, nu la Finalizate; jurnalul păstrează etapele rămase. Piesele deja reținute sunt eliberate când ieșirea este pornită. Mutarea ieșirii resetează simularea; schimbarea acestei opțiuni nu o resetează.

8. Imagini pentru linie și produs

În Imagini de prezentare introdu un titlu, selectează Peste linie / stație sau Pe produs, alege etapa, dimensiunea și fișierul imagine. Apasă Adaugă imagine. Pentru imaginile de pe produs poți reprezenta vizual diferite stadii de fabricație. Poți reasigna oricând o imagine existentă folosind câmpurile Tip și Asociere de sub imagine. Imaginea piesei se schimbă după etapa selectată. Folosește imagini mici pentru a evita limitele de stocare ale browserului.

9. Date JSON și evenimente

În Evenimente configurabile selectează stația și momentul (sosire, ridicare, început, finalizare, repunere). Completează un obiect JSON valid și apasă Aplică JSON. Exemplu:

{
  "serial": "{{pieceId}}",
  "station": "{{stationName}}",
  "result": "OK",
  "torque_nm": 2.5
}

Variabile disponibile: {{pieceId}}, {{stationId}}, {{stationName}}, {{event}}, {{time}}, {{timestamp}}, {{cycle}}. Apasă Previzualizare pentru un exemplu. Evenimentele apar doar în jurnal; Export JSON descarcă evenimentele înregistrate.

10. Salvare, import și export

  • Salvează configurația: încearcă să o păstreze local în browser.
  • Export configurație: descarcă un fișier JSON cu parametrii și imaginile.
  • Import configurație: încarcă un fișier JSON exportat anterior.
  • Reset simulare: golește piesele și statisticile, păstrând configurarea.
Notă: Simulatorul este un instrument demonstrativ offline, nu un controler industrial. Unele reguli de rutare și de capacitate sunt simplificate. Salvează periodic configurația prin export JSON, în special când folosești imagini.

User guide — Production Line Simulator

This application locally simulates a continuously moving oval conveyor, processing stations, handling robots, alternative routes and unloading. No data is sent to a server.

1. Getting started

  1. Open the HTML file in Chrome or Edge.
  2. Choose Black / White / Grey view and RO / EN language.
  3. Configure conveyor shape, input, output and direction.
  4. Add stations and configure times, capacities and routing.
  5. Use Resume to run or Pause to stop temporarily.
  6. Monitor parts and the JSON event log.

2. Conveyor settings

  • Belt layout: round loop, oval loop or straight active run with a narrow empty return.
  • Straight section length: sets the active straight run for oval and straight layouts.
  • Diameter: sets the height of the round loop or oval.
  • Conveyor width: changes the visual thickness.
  • Clockwise / Counterclockwise: changes direction on closed loops.
  • Input / Output: drag the markers or move their labels separately.
  • LINE semaphore: stops or starts all operations, including material feeders.

3. Adding and moving stations

Click + Process for a simple station or + Robot + process for a robot that picks up a part and transfers it to an off-belt process. Drag a station marker on the conveyor or enter its position percentage. Delete removes a station. Structural edits may reset parts in the current simulation.

4. Station parameters

  • Name: displayed station name.
  • Total capacity: maximum number of parts in the station buffer and stages.
  • Process duration: operation time.
  • Parallel processing slots: number of parts processed at once.
  • Pickup / Return: part-handling times.
  • Robot: travel time per direction and concurrent handling capacity.
  • FAIL rate (%): simulated probability of a NOK result after processing.

5. Parallel alternatives and routing

Assign the same Alternative group to up to 8 stations (e.g. GROUP_A). Enter ST01,GROUP_A,ST05 in Processing sequence, then click Apply route. At GROUP_A, a part can be handled by an available station in that group. The sequence is calculated automatically from physical station positions and conveyor direction. This is sequence/group routing, not a full IF/ELSE programming editor.

6. FAIL and NOK locations

Set a FAIL rate from 0 to 100% on each station. Use + NOK position to add reject locations, then drag or rename them. Failed parts generate process_failed and are routed to a configured NOK position.

7a. Conveyor traffic light and interprocess buffers

Configure the maximum waiting buffer per station (0–500 parts). When a station is full, parts accumulate physically before it. A full local buffer propagates backpressure upstream, but downstream stations keep running. Feeding continues while INPUT has room. RED indicates local saturation, not a global conveyor stop. A value of 0 means no waiting buffer.

7. Cascading blocking (capacity + BEFORE buffer)

The overloaded station keeps processing; only its preceding station is interlocked. If the first station is full, the feeder is interlocked. When the next station occupancy plus its BEFORE-buffer count reaches the configured sum, the previous station output is blocked. Its completed part waits at the previous station until capacity becomes available. Blocking propagates upstream while downstream stations continue working.

8. Exit buffer

Set Unloading duration / part and Concurrent unloading capacity. The exit buffer holds up to 1,000 waiting parts; when full, parts wait on the conveyor until space becomes available. Only fully unloaded parts count as completed. Incomplete parts are held separately, up to 1,000; reaching this limit blocks feeding. The log exports the latest 5,000 events while the counter shows the total since reset. Browsers may suspend inactive tabs; for continuous operation keep this tab active, disable memory saving for it and prevent computer sleep.

Incomplete unloading: the displayed order includes INPUT and OUTPUT. Enable Allow unloading incomplete parts to remove parts at OUTPUT even if processing stages remain. They count as Incomplete unloaded, not Completed; events record the remaining stages. Previously held parts are released when OUTPUT is running. Moving OUTPUT resets the simulation; changing this option does not.

8. Conveyor and product images

Under Presentation images, enter a title, choose Over conveyor / station or On product, select the station/stage, size and image file, then click Add image. Product images can illustrate manufacturing stages. Reassign any existing image using the Type and Assignment fields below its preview. A part image updates after the selected stage. Prefer small files to avoid browser storage limits.

9. JSON events

Under Configurable events, select a station and trigger (arrival, pickup, process start, completion, return). Enter a valid JSON object and click Apply JSON. Example:

{
  "serial": "{{pieceId}}",
  "station": "{{stationName}}",
  "result": "OK",
  "torque_nm": 2.5
}

Available placeholders: {{pieceId}}, {{stationId}}, {{stationName}}, {{event}}, {{time}}, {{timestamp}}, {{cycle}}. Click Preview to inspect an example. Events appear only in the local log; Export JSON downloads recorded events.

10. Save, import and export

  • Save configuration: attempts to save settings in the browser.
  • Export configuration: downloads a JSON file containing settings and images.
  • Import configuration: loads a previously exported JSON file.
  • Reset simulation: clears parts and counters but retains settings.
Note: This is an offline demonstration tool, not an industrial controller. Some routing and capacity rules are simplified. Export your configuration regularly, especially when using images.
